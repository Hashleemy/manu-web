# Drop photos here

Save each photo with the **exact file name** below and it appears on the site at the next build.
Until a file exists, that spot shows a labeled placeholder frame.

| File name | Where it appears | Orientation / minimum size |
|---|---|---|
| `manuela-portrait.jpg` | About section (organic oval frame) | Portrait 3:4, at least 1200 × 1600 px |
| `jersey-shore.jpg` | Jersey Shore section | Portrait 4:5, at least 1200 × 1500 px |
| `og-image.jpg` | Link previews on iMessage / WhatsApp / Facebook | Landscape 1200 × 630 px exactly |
| `listing-1.jpg` … `listing-6.jpg` | Featured Listings cards (one per listing `id` in `src/data/listings.js`) | Landscape 4:3, at least 1200 × 900 px |

JPG, PNG and WebP all work. Astro resizes and compresses automatically, so send the largest original available.
